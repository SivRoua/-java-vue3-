# 智能农业系统

## 项目概况

智能农业系统是一个基于物联网技术的温室自动化控制平台,通过对温室内环境参数的实时监测和设备的智能控制,实现农业生产的自动化和精准化管理。系统采用前后端分离架构,后端使用Python Flask框架开发,前端使用Vue.js和Element Plus组件库构建用户界面。

系统通过网络与虚拟硬件平台进行通信,控制温室内的各种设备,如通风系统、喷灌系统、天窗、水帘和照明等,同时监测温室内的温度、湿度、光照强度和CO2浓度等环境参数。

## 系统架构

### 后端架构

- **Web服务器**: Flask框架提供RESTful API接口
- **数据库**: MySQL存储传感器数据、设备状态和操作日志
- **设备控制模块**: 通过TCP/IP协议与虚拟硬件平台通信
- **数据处理模块**: 处理和分析传感器数据

### 前端架构

- **框架**: Vue.js 3 + Vite
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios## 主要功能

1. **设备控制**:
   - 控制温室内各种设备的开关状态
   - 实时显示设备运行状态
   - 支持手动控制和自动控制模式

2. **环境监测**:
   - 实时监测温室内的温度、湿度、光照强度和CO2浓度
   - 历史数据查询和图表展示
   - 异常数据报警

3. **用户管理**:
   - 用户登录和权限控制
   - 操作日志记录

## 硬件连接

系统通过TCP/IP协议与虚拟硬件平台通信,控制继电器实现设备控制：

- **继电器1 (地址: 0x2001)**:
  - 端口1: 外部通风系统
  - 端口2: 内部通风系统

- **继电器2 (地址: 0x2003)**:
  - 端口1: 天窗控制
  - 端口2: 喷灌系统
  - 端口3: 水帘系统
  - 端口4: 照明系统## 安装与运行

### 后端

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### 前端

```bash
cd frontend
npm install
npm run dev
```
