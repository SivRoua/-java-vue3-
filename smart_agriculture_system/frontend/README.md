# 智能农业系统 - 前端

## 项目概述

智能农业系统前端是使用Vue.js 3和Element Plus构建的现代化Web应用程序，为用户提供温室环境数据监控和设备控制的图形化界面。通过直观的仪表盘、实时数据图表和设备控制面板，用户可以方便地管理农业温室环境。

## 技术栈

- **框架**: Vue.js 3 + Vite
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios
- **图表库**: ECharts

## 开发指南

### 数据获取频率
系统配置为每**2分钟**（120秒）获取一次传感器数据和设备状态，以减少不必要的网络请求和服务器负担。此频率适用于农业环境监测，因为农业环境参数通常变化缓慢。所有前端组件的定时更新都已同步调整为此频率。

### API请求
所有API请求都在`src/api`目录下进行集中管理，使用Axios进行HTTP通信。

### 组件开发
- 公共组件位于`src/components`目录
- 页面组件位于`src/views`目录
- 组件命名使用PascalCase规范

### 状态管理
使用Pinia进行状态管理，store定义在`src/store`目录下。

## 跨域配置
开发环境下，通过Vite的proxy功能处理跨域请求，配置在`vite.config.js`文件中。
